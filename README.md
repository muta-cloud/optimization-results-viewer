# 最適化結果グラフビューア

7種類のインタラクティブな6グラフを切り替えて表示する、GitHub Pages向けの静的サイトです。

## 公開方法

1. このフォルダの内容をGitHubリポジトリの既定ブランチへ配置します。
2. リポジトリの `Settings` → `Pages` を開きます。
3. `Build and deployment` の `Source` を `Deploy from a branch` にします。
4. 既定ブランチと `/ (root)` を選択して保存します。

公開後は `https://<ユーザー名>.github.io/<リポジトリ名>/` で閲覧できます。URL末尾のハッシュ（例: `#seed-7`）を含めて共有すると、指定したグラフを直接表示できます。

## 収録グラフ

- 3手法比較
- 3手法比較（モバイル版）
- 磁石量・トルク制約あり
- 制約を満たす結果のみ
- シード値6
- シード値7
- シード値8

グラフHTMLは `graphs/` に収録しています。ビューアは各HTMLをそのまま読み込むため、グラフ本体のフォント、軸、配色、再生機能は変更していません。
